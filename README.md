# TooManyEmotes Addon Fix

Fixes two problems with TooManyEmotes addons like
[Alone's TooManyEmotes](https://thunderstore.io/c/lethal-company/p/aloneluvsya/Alones_TooManyEmotes/):

- **Addon emotes are free for everyone.** Now they get a rarity tier and have to be bought
  from the store, like the base emotes. Longer dances get a rarer tier.
- **Some base emotes break.** Missing props (sax, dumbbell, jug band), broken poses, random
  emotes that don't pick (death pose, rock paper scissors). Now they work again.

Works with new emotes from addon updates without needing an update itself. Also shows up in
Y4NGZUpgrades' emote menu.

## Notes

- Everyone in the lobby needs it.
- Tested with Alone's TooManyEmotes, other addons should work too.
- AI-assisted mod. Tested in a lightweight profile and in a ~260-mod modpack.
- Found a bug? Open an issue.

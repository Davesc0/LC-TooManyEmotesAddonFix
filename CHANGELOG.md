# Changelog

## 0.2.0
- Config: addon emotes can stay unlocked while still getting a tier (`MustBeBought`).
- Config: tier lengths can be changed, and single emotes can be given a tier by name.

## 0.1.0
- First version: free emotes from TooManyEmotes addons get a tier from their animation length
  and are bought from the store like the base emotes.
- Addon emote names keep the casing of their clip.
- Repairs the emote list after an addon rebuilds it: props, music, poses, random emotes and band
  layers of the base emotes work again.
